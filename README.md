# WheelAppSA – GIS Mapping of Accessibility in Sarajevo

**Project Type:** GIS Analysis + Informational Web App  
**Technologies:** QGIS, PostgreSQL, Leaflet.js, HTML/CSS/JS  
**Languages:** Bosnian and English    

## Overview

**WheelAppSA** is a GIS-based mapping project aimed at assessing and visualizing the accessibility of public facilities for people with disabilities in Sarajevo. The core outcome is an interactive bilingual web map that displays the spatial distribution and accessibility classification of buildings across categories such as:

- Health  
- Education  
- Sport  
- Shopping  
- Parking  
- Institutions  

Each object is marked by accessibility level (Accessible, Partially Accessible, Not Accessible) using color-coded indicators.

## Key Features

- Combined **field** and **administrative data collection**
- Spatial data modeling and classification using **QGIS**
- Basic database structuring using **PostgreSQL**
- Exported map using **QGIS2Web** with **Leaflet**
- Multilingual interface: **Bosnian** and **English** (for local and tourist use)
- Visual legends and filters by object type and accessibility level

## Context

This project was developed as part of a university GIS module and extended for real-world social impact.

The digital solution aims to raise awareness and improve transparency regarding urban accessibility in Sarajevo.

## How to Use

1. Open the web page (simple static HTML).
2. Select language (BS or EN).
3. Use legend filters to explore accessibility by category.
4. Hover or click on icons for detailed info about each object.
